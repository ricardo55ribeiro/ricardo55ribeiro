# Ricardo Ribeiro

MSc student in **Computer Science and Engineering** at **Instituto Superior Técnico**, specializing in Artificial Intelligence and Distributed Systems. I hold a BSc in Engineering Physics.

My interests include Scientific Machine Learning, Reinforcement Learning, AI Agents and Reliable ML Systems. I am developing my research and engineering skills through experimental work and open-source contributions. I'm happy to discuss research and potential collaborations.

## Research and Projects

**[Inverse Estimation of Oxygen Plasma Kinetics](https://github.com/ricardo55ribeiro/inverse-estimation-oxygen-plasmas-ML)**

Scientific machine learning project using PyTorch neural networks to estimate reaction-rate coefficients from simulated plasma densities. Investigated input-species selection, model ensembles and robustness to noisy inputs. Includes datasets, experimental code and a [research report](https://github.com/ricardo55ribeiro/inverse-estimation-oxygen-plasmas-ML/blob/main/docs/Report.pdf).

**[Agent-Safety Evaluation: Research Contribution](https://github.com/hasandemirkiran/shortcut-sensitivity-agent-safety-evaluations/pull/1)**

Merged a post-publication extension to *Shortcut Sensitivity in Agent-Safety Evaluations*. Investigated how evaluation-unit weighting affects AgentDojo lookup metrics using grouped cross-validation, domain holdouts and bootstrap analysis. [Code and results](https://github.com/hasandemirkiran/shortcut-sensitivity-agent-safety-evaluations/tree/main/extensions/agentdojo_lookup_weighting).

**[Traffic Lights Reinforcement Learning Agent](https://github.com/ricardo55ribeiro/TrafficLightsGame-AI)**

Tabular Q-learning RL agent for the Alan Parr's Traffic Lights game, including self-play, configurable opponent curricula, evaluation baselines and an interactive desktop interface.

**[TrackStudy](https://github.com/ricardo55ribeiro/TrackStudy)**

Local-first study and research tracker for Windows and Android, built with Flutter. Includes research journaling, weekly planning, scheduling and optional cross-device synchronization.

**[FocusGuard](https://github.com/ricardo55ribeiro/Focus-Guard)**

Experimental Windows productivity application using local language models and browser integration to identify potentially distracting activity. Includes configurable rules.
